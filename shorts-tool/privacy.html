プライバシーポリシー

Privacy Policy ・ 2026年11月16日 制定 / Effective November 16, 2026

1. 集める情報 / Information we collect

本ツールが扱うのは、運営者本人が TikTok・YouTube・Instagram で連携を許可したときに受け取る「アクセストークン」（投稿のための合い言葉）と、TikTok の基本情報（表示名など）だけです。運営者以外の方の情報は集めません。

The Tool only handles the access tokens issued when the operator authorizes their own TikTok, YouTube and Instagram accounts, plus basic TikTok profile info (such as display name). No information about anyone other than the operator is collected.

2. 使い方 / How it is used

受け取った情報は、運営者本人のアカウントへ動画を送るためだけに使います。

This information is used solely to upload videos to the operator's own accounts.

3. 保存場所 / Storage

情報は運営者のパソコンの中にだけ保存し、外部のサーバーには送りません（各サービスの公式 API への送信を除く）。

Data is stored only on the operator's own computer and is not sent to any server other than the official APIs of each platform.

4. 第三者への提供 / Sharing

情報を第三者へ渡したり、売ったりすることはありません。

We do not share or sell any data to third parties.

5. 削除 / Deletion

連携は各サービスの設定画面からいつでも取り消せます。取り消すと、保存してあるトークンは使えなくなり、運営者が削除します。

Authorization can be revoked at any time from each platform's settings; stored tokens are then deleted.

6. 変更 / Changes

このポリシーは、このページを更新することで変更することがあります。

This policy may be updated by revising this page.
